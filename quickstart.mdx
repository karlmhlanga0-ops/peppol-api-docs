---
title: "Quickstart"
description: "Send your first compliant invoice in minutes."
---

This guide will walk you through authenticating and dispatching your first legally compliant UBL 2.1 e-invoice using the Octothorp API.

<Steps>
  <Step title="Get your API Keys">
    Log in to your [Developer Dashboard](https://peppol.octothorp.online) and navigate to the **API Keys** section. You will need your `sk_test_...` key for this tutorial. 
    
    <Warning>Never expose your secret keys in client-side code.</Warning>
  </Step>

  <Step title="Construct the Payload">
    The Octothorp API accepts standard JSON. You do not need to format any XML. Map your internal order data to our standard schema.

    ```json Invoice Payload
    {
      "jurisdiction": "ZA-SARS",
      "buyer_tin": "9123456789",
      "total_amount": 1500.00
    }
    ```
  </Step>

  <Step title="Fire the Request">
    Send a `POST` request to the `/invoices/clear` endpoint. You can test this directly in your terminal.

    <CodeGroup>
    ```bash cURL
    curl -X POST "[https://api.octothorp.online/v1/invoices/clear](https://api.octothorp.online/v1/invoices/clear)" \
      -H "Authorization: Bearer sk_test_12345" \
      -H "Content-Type: application/json" \
      -d '{"jurisdiction": "ZA-SARS", "buyer_tin": "9123456789", "total_amount": 1500.00}'
    ```
    ```javascript Node.js
    const response = await fetch('[https://api.octothorp.online/v1/invoices/clear](https://api.octothorp.online/v1/invoices/clear)', {
      method: 'POST',
      headers: {
        'Authorization': 'Bearer sk_test_12345',
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        jurisdiction: 'ZA-SARS',
        buyer_tin: '9123456789',
        total_amount: 1500.00
      })
    });
    const data = await response.json();
    ```
    </CodeGroup>
  </Step>

  <Step title="Handle the Webhook">
    Because government clearance is asynchronous, the API returns a `200 OK` indicating the payload was received. The actual cryptographic clearance ID will be sent to your webhook endpoint once the tax authority validates the invoice.
  </Step>
</Steps>
